Bir test, səhv girişlər cədvəli
@pytest.mark.parametrize(
"payload, expected",
[
(valid, 200), # control
(bad_pw, 401),
(missing, 400),
])
pytest -v
test_login[valid] PASSED
test_login[bad-password] PASSED
test_login[missing] PASSED
Bir valid kontrol sətri saxla — onda uğursuz olan neqativ sətir giriş haqqındadır, sınmış endpoint haqqında yox.
