import re
from playwright.sync_api import expect
def test_products_page(page):
page.goto("http://localhost:3000/products")
expect(page).to_have_title(re.compile("TestMarket Lab"))

Təkrar cəhd edən assert-lər
from playwright.sync_api import expect
# waits until it's visible, or fails
expect(
page.get_by_test_id("nav-logout")
).to_be_visible()
✅expect(locator) şərt doğru olana və ya timeout çatana qədər avtomatik təkrar cəhd edir — bir millisaniyə erkən assert etməkdən flake yox.
🆚pytest-in sadə assert-indən fərqli: web-first expect bir dəfə yoxlamaq əvəzinə canlı səhifəni yoxlayır (poll).
