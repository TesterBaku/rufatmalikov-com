pytest.approx — float-ları müqayisə et
assert 0.1 + 0.2 == pytest.approx(0.3)
# plain == 0.3 would FAIL
Floating-point riyaziyyatı dəqiq deyil — hesablanmış qiymətləri və ya cəmləri heç vaxt çılpaq == ilə müqayisə etmə.
