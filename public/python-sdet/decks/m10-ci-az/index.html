🚪Fayda tələb olunan yoxlamadır: dəst CI-nin təmiz maşınında keçənə qədər PR birləşə bilmir — sadəcə "mənim noutbukumda işləyir" yox.
AI with Rufat
.github/workflows/-da bir YAML fayl
# .github/workflows/tests.yml
name: tests
on:
push: { branches: [main] }
pull_request:
jobs:
test:
runs-on: ubuntu-latest
steps: …
🧱Bir name, bir on: tətikləyici və steps-dən ibarət jobs.
🔩Hər addım ya uses: (hazır action) ya da run: (shell əmrləri)-dir. push-u main-ə scope-lamaq branch push-unun və onun PR-ının hər ikisinin işləməsini dayandırır.

İnsanları büdrədən iki təfərrüat
# background the app, then WAIT
npm start &
for i in $(seq 1 30); do
curl -sf localhost:3000/api/products \
&& exit 0
sleep 1
done; exit 1 # never started
⏳npm start & dərhal qayıdır — real endpoint-i cavab verənə qədər yoxla, sabit təxmini sleep etmə.
🐧playwright install --with-deps chromium — headless runner-in Linux kitabxanalarına da ehtiyacı var.
💾if: always() ilə yüklə — testlər uğursuz olanda belə hesabatı saxla (məhz onu istədiyin an).
