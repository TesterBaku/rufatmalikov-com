yield-dən əvvəl qur, sonra təmizlə
@pytest.fixture
def temp_product(api, base_url):
# setup
p = api.post(…/products).json()
yield p # hand it to the test
# teardown — always runs
api.delete(f"…/products/{p['id']}")
♻️yield-dən əvvəlki kod quraşdırmadır; sonrakı kod söküşdür — və test uğursuz olsa belə işləyir.
🏭Bir neçəsi lazımdır? Factory fixture-i testin N dəfə çağırdığı bir funksiya qaytarır — hər biri unikal adla, və reset_db sonra hamısını yenidən səpərək aparır.
