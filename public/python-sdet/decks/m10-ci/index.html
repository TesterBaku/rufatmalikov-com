AI with Rufat
One YAML file in .github/workflows/
# .github/workflows/tests.yml
name: tests
on:
push: { branches: [main] }
pull_request:
jobs:
test:
runs-on: ubuntu-latest
steps: …
🧱A name, an on: trigger, and jobs made of steps.
🔩Each step is either uses: (a prebuilt action) or run: (shell commands). Scoping push to main stops a branch push and its PR both running.

Two details that trip people up
# background the app, then WAIT
npm start &
for i in $(seq 1 30); do
curl -sf localhost:3000/api/products \
&& exit 0
sleep 1
done; exit 1 # never started
⏳npm start & returns immediately — poll a real endpoint until it answers, don't sleep a fixed guess.
🐧playwright install --with-deps chromium — the headless runner needs the Linux libs too.
💾Upload with if: always() — keep the report even when tests fail (that's when you want it).
