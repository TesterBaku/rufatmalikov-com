A single shareable report file
bash
# install once, then re-pin
pip install pytest-html
pip freeze > requirements.txt
pytest --html=report.html \
--self-contained-html
📄Lists every test — outcome, duration, captured output, failing tracebacks inline.
📎--self-contained-html inlines the CSS/JS, so the one file is emailable or uploadable as a CI artifact.
AI with Rufat
Tag a subset, run just that subset
# pytest.ini
[pytest]
markers =
smoke: fast, critical subset
api: hits the REST API
ui: drives the browser
@pytest.mark.smoke
def test_products_up(): …
pytest -m smoke
pytest -m "api and not smoke"
pytest -m ui
🚦-m supports and/or/not. A seconds-long smoke subset is your everyday "did we break anything critical?" gate.
AI with Rufat
Group by area, share fixtures by folder
tests/
├── conftest.py # shared
├── api/
│ ├── conftest.py
│ └── test_products.py
└── ui/
├── conftest.py
└── test_login.py
🗂️pytest loads every conftest.py on the path to a test — no imports.
🎯Top conftest.py = shared fixtures (everywhere); a nested one = scoped to that area. Central shared, local specific.

Legible input, legible output

One command: fast subset · artifact · clean summary

pytest -m smoke --html=smoke-report.html \
--self-contained-html -ra --tb=short
-m smoke fast subset
--html artifact
-ra skips/xfails
--tb=short compact
🧾Also handy: --durations=10 (slowest tests) and -q (one char per test). Module 10 wires this exact gate into GitHub Actions.
