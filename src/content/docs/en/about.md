Hi, I'm **Rufat Malikov** — a QA automation engineer with 9+ years in the field, and this site is where I teach what I've learned, for free.

The courses take you from zero into test automation: a 15-module [Playwright course](/en/course/) in English and Azerbaijani, a beginner-friendly [Python Fundamentals](/en/python/) course, [Python for SDETs](/en/python-sdet/) for the step into real API and UI testing, and a plain-language [Reference](/en/reference/) library. You learn the concepts, practice hands-on in [BrauzerLab](/en/playwright/) — a free in-browser Playwright trainer I built — then write full test suites against TestMarket Lab, a real app you run locally. Everything here is free.

**Why learn from me:** I've spent 9+ years building and stabilizing end-to-end test automation across web, mobile, REST APIs, and AWS-native data pipelines — the high-stakes, unglamorous side of quality: flaky-test remediation, release-gate go/no-go calls, and source-to-target data validation for ETL pipelines. I've worked across Selenium, Playwright, Appium, and XCUITest — in Java, Python, and C# — with deep AWS and SQL experience.

These days I'm especially interested in **AI-assisted testing**: using Claude, Claude Code, and MCP-based agentic tooling to speed up test authoring, generate realistic test data, and spot defect patterns. That's also what I explore on my YouTube channel, [AI with Rufat](https://www.youtube.com/@AIwithRufat).

Beyond the courses, I build free QA and study tools — an [exam-prep app for students in Azerbaijan](/en/exam-helper/), an interview trainer, and more on the [projects page](/en/projects/).

I'm also currently open to QA automation / SDET roles — remote, hybrid, or on-site.
