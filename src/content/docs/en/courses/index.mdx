Four free learning tracks, all in English and Azerbaijani. Here's how to pick your starting point.

## Which one is right for you?

| If you… | Start with |
|---|---|
| have **never written code** | [Python Fundamentals](/en/python/) — runs in your browser, nothing to install |
| know **some HTML/CSS/JS** and want to test the web | [Playwright course](/en/course/) |
| know **Python basics** and want a real testing job skill | [Python for SDETs](/en/python-sdet/) |
| just want to **practice** in the browser | [BrauzerLab](/en/playwright/) — 100 hands-on Playwright missions |
| need a **term explained** (HTTP, SQL, Git, selectors…) | [Reference](/en/reference/) |

## The two paths

Most people follow one of two routes.

**The Python path** — start with [Python Fundamentals](/en/python/) to learn to code from zero, then move on to [Python for SDETs](/en/python-sdet/) to turn that into a real test-automation skill set (pytest, requests, Playwright, CI).

**The JavaScript path** — if you already know a little JS and HTML, go straight to the [Playwright course](/en/course/), and practice alongside it in [BrauzerLab](/en/playwright/).

Both paths test the same real app — TestMarket Lab — so the skills carry over. And whenever a term is new, the [Reference](/en/reference/) has a short, plain-language primer.

Everything here is free, with no sign-up.
