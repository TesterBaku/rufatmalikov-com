A list is alive: points get added during a game, products land in a basket, rankings shift. A list has its own **methods** — operations you call with a dot.

## Add, remove

<PyRunner
	id="ex-append"
	starterCode={`groceries = ["bread", "milk"]\ngroceries.append("cheese")\nprint(groceries)\ngroceries.remove("milk")\nprint(groceries)`}
	height="6rem"
/>

- `.append(x)` — adds to the end
- `.remove(x)` — removes the first `x` it finds

## Sort

<PyRunner
	id="ex-sort"
	starterCode={`scores = [42, 7, 99, 23]\nscores.sort()\nprint(scores)\n\nnames = ["Tural", "Aysel", "Nigar"]\nnames.sort()\nprint(names)`}
	height="6rem"
/>

`.sort()` arranges numbers from smallest to largest, and text in alphabetical order.

## in — "is it inside?"

`in` checks whether an item is in the list — the result is `True`/`False`, so it plugs straight into an `if`:

<PyRunner
	id="ex-in"
	starterCode={`guests = ["Aysel", "Tural", "Nigar"]\nif "Tural" in guests:\n    print("Come on in! 🎉")\nelse:\n    print("Your name isn't on the list.")`}
	height="6rem"
/>
