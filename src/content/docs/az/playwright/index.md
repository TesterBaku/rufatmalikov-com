Bu bölmə **BrauzerLab**-ın evidir — pulsuz, interaktiv Playwright məşqçisi. Brauzerinizdə real Playwright (JavaScript/TypeScript) kodu yazırsınız, simulyasiya olunmuş səhifənin necə reaksiya verdiyini görürsünüz və dərhal keç/keçmə rəyi alırsınız — quraşdırma və ya hazırlıq tələb olunmur.

## Nə məşq edəcəksiniz

7 mərhələli modul üzrə 50 praktiki tapşırıq:

1. **Lokatorlar** — rol, mətn, label, test-id, filter və mövqe selektorları ilə istənilən elementi tapın (Shadow DOM və dinamik id-lər daxil)
2. **Əməliyyatlar** — klik, yazı, formalar, klaviatura, açılan siyahılar, drag-and-drop və hover
3. **Avtomatik gözləmə** — flaky `sleep` çağırışları olmadan etibarlı test yazın
4. **Ciddi rejim** — qeyri-müəyyən lokatorları təmiz həll edin
5. **İddialar** — mətn, say, atribut və vəziyyəti avtomatik gözləyən `expect` ilə yoxlayın
6. **Şəbəkə müdaxiləsi** — `page.route` ilə sorğuları bloklayın, mock edin və əvəzləyin
7. **Çoxaddımlı ssenarilər** — hər şeyi real end-to-end ssenarilərdə birləşdirin

## Bu kim üçündür

HTML, CSS və JavaScript-in əsasları ilə rahat olan, Playwright ilə brauzer avtomatlaşdırmasını öyrənmək istəyən hər kəs — əvvəlcədən Playwright təcrübəsi tələb olunmur.
