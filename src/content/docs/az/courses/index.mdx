Hamısı ingilis və Azərbaycan dilində olan dörd pulsuz öyrənmə istiqaməti. Başlanğıc nöqtəni belə seç.

## Hansı sənə uyğundur?

| Əgər sən… | Bununla başla |
|---|---|
| **heç vaxt kod yazmamısansa** | [Python Əsasları](/az/python/) — brauzerdə işləyir, heç nə quraşdırmaq lazım deyil |
| **bir az HTML/CSS/JS** bilirsən və vebi test etmək istəyirsən | [Playwright kursu](/az/course/) |
| **Python əsaslarını** bilirsən və real test işi bacarığı istəyirsən | [SDET-lər üçün Python](/az/python-sdet/) |
| sadəcə brauzerdə **məşq etmək** istəyirsən | [BrauzerLab](/az/playwright/) — 100 praktiki Playwright tapşırığı |
| bir **termin izahına** ehtiyacın var (HTTP, SQL, Git, selektorlar…) | [İstinad](/az/reference/) |

## İki yol

Əksər insanlar iki marşrutdan birini izləyir.

**Python yolu** — sıfırdan kod yazmağı öyrənmək üçün [Python Əsasları](/az/python/) ilə başla, sonra bunu real test-avtomatlaşdırma bacarığına çevirmək üçün [SDET-lər üçün Python](/az/python-sdet/)-a keç (pytest, requests, Playwright, CI).

**JavaScript yolu** — bir az JS və HTML bilirsənsə, birbaşa [Playwright kursuna](/az/course/) get və onunla yanaşı [BrauzerLab](/az/playwright/)-də məşq et.

Hər iki yol eyni real tətbiqi — TestMarket Lab — test edir, ona görə də bacarıqlar köçürülür. Hansısa termin yeni olanda, [İstinad](/az/reference/)-da qısa, sadə dildə izah var.

Buradakı hər şey pulsuzdur, qeydiyyat tələb olunmur.
