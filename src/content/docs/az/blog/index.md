Yazılar burada görünəcək. Yazmağı planlaşdırdığım mövzular:

- Test arxitekturası qərarları və onların zamanla necə dəyişməsi
- Agent sistemləri və MCP serverləri qurmaq
- 2026-cı ildə test avtomatlaşdırmasının vəziyyəti

Əgər bir yazı azərbaycan dilində daha yaxşı oturursa, ilk olaraq orada yayımlanır — və əksinə. Hər yazı hər iki dildə olmayacaq.
