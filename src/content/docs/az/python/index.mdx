Salam! 👋 Bura **Azərbaycan dilində pulsuz Python kursudur** — orta və yuxarı sinif şagirdləri üçün.

Heç nə quraşdırmaq lazım deyil. Kod birbaşa **brauzerdə** yazılır və işə salınır — telefonda da, məktəb kompüterində də işləyir.

## Kurs necə işləyir?

1. **Oxu** — hər dərs qısadır: 5–10 dəqiqə.
2. **İşə sal** — dərsin içindəki nümunələri özün işə sal, dəyiş, sınaqdan keçir.
3. **Missiyanı tamamla** — hər dərsin sonunda kiçik tapşırıqlar var. Kodun yoxlanılır və düz olanda **XP qazanırsan**. ⭐
4. **Nişan topla** — modulun bütün missiyalarını bitirəndə nişan (badge) alırsan. 🏅

:::note[İrəliləyişin harada saxlanılır?]
XP və nişanların bu brauzerdə yadda saxlanılır — qeydiyyat, parol, hesab lazım deyil. Başqa cihazda davam etsən, oradakı irəliləyiş sıfırdan başlayır.
:::
