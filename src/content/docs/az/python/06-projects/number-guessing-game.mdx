Modul 03-da «Ədədi tap» yazmışdın. İndi onu **əsl oyuna** çevirək: proqram hər səhv cəhddə ipucu versin və sonda neçə cəhd lazım olduğunu desin.

:::tip[Bu layihədə işlədəcəksən]
`while` (Modul 03) · `if/elif` (Modul 02) · sayğac dəyişən (Modul 03) · f-string
:::

## Plan

1. `gizli = 7` və `cehd = 0` ilə başla
2. İlk cavabı oxu (`int(input(...))`) və cəhdi say
3. `while cavab != gizli:` — tapılmayana qədər:
   - cavab gizlidən **kiçikdirsə**: «Gizli ədəd daha böyükdür ⬆️»
   - **böyükdürsə**: «Gizli ədəd daha kiçikdir ⬇️»
   - yeni cavab oxu, cəhdi yenə say
4. Dövr bitəndə: `f"Tapdın! {cehd} cəhdə 🎉"`
