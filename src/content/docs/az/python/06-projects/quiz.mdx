Müəllimlər Kahoot işlədir, sən özünküni **yazacaqsan**. Suallar və cavablar siyahılarda, dövr onları bir-bir verir, düz cavaba xal.

:::tip[Bu layihədə işlədəcəksən]
Siyahılar + indeks (Modul 04) · `for` + `range` (Modul 03) · `if` (Modul 02) · toplayıcı (Modul 03)
:::

## Plan

1. İki **paralel siyahı** yarat: `suallar` və `cavablar` — eyni indeksdə sual və onun cavabı
2. `xal = 0`
3. `for i in range(len(suallar)):` — hər sual üçün:
   - sualı göstər: `input(suallar[i])`
   - cavab `cavablar[i]`-yə bərabərdirsə: «Düzdür! ✅» + xal
   - deyilsə: «Səhvdir ❌»
4. Sonda: `f"Nəticə: {xal}/{len(suallar)}"`
