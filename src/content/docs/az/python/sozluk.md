---
title: Sözlük
description: Kursda işlənən proqramlaşdırma terminləri — Azərbaycanca və ingiliscə qarşılıqları ilə.
---

Proqramlaşdırma dünyasının öz dili var. Bu səhifə kursda işlənən terminlərin lüğətidir — ingiliscə qarşılıqları ilə birlikdə, çünki internetdə axtarış edəndə ingilis termini lazım olacaq.

| Azərbaycanca | İngiliscə | İzahı |
|---|---|---|
| proqram | program | Kompüter üçün addım-addım təlimatlar toplusu |
| proqramlaşdırma | programming, coding | Proqram yazmaq işi |
| kod | code | Proqramın mətni |
| əmr | command, statement | Kompüterə verilən bir təlimat |
| işə salmaq | run, execute | Proqramı başlatmaq |
| çap etmək | print | Ekrana yazı çıxarmaq |
| mətn | string | Dırnaq içində yazılan simvollar ardıcıllığı |
| tam ədəd | integer (int) | Kəsrsiz ədəd: 5, -3, 1024 |
| kəsr ədəd | float | Vergüllü ədəd: 3.5, 0.1 |
| dəyişən | variable | Məlumat saxlayan adlı «qutu» |
| mənimsətmə | assignment | Dəyişənə dəyər vermək: `x = 5` |
| daxiletmə | input | İstifadəçidən alınan məlumat |
| çıxış, nəticə | output | Proqramın ekrana çıxardığı məlumat |
| xəta | error | Proqramda problem — Python onun yerini göstərir |
| sintaksis xətası | syntax error | Yazılış qaydası pozulanda çıxan xəta |
| şərh | comment | `#` ilə başlayan, kompüterin oxumadığı qeyd |
| f-string | f-string | İçində `{dəyişən}` işlədilə bilən mətn |
| çevirmə | conversion, casting | Tipi dəyişmək: `int("12")` |
| şərt | condition | Doğru/yanlış yoxlanılan ifadə |
| girinti | indentation | Sətrin əvvəlindəki boşluqlar — Python blokları belə tanıyır |
| müqayisə | comparison | İki dəyəri tutuşdurmaq: `==`, `!=`, `<`, `>` |
| doğru / yanlış | True / False (boolean) | Python-un «hə» və «yox» dəyərləri |
| məntiqi operator | logical operator | Şərtləri birləşdirən `and`, `or`, `not` |
| dövr | loop | Təkrarlanan kod bloku |
| sayğac | counter | Dövrədə dəyəri artan/azalan dəyişən (`i`) |
| toplayıcı | accumulator | Dövr boyu nəticə yığan dəyişən |
| sonsuz dövr | infinite loop | Heç vaxt bitməyən dövr — `while` yazanda diqqət! |
| siyahı | list | Sıra ilə düzülmüş elementlər toplusu *(Modul 04)* |
| lüğət | dictionary (dict) | Açar–dəyər cütlükləri saxlayan struktur *(Modul 04)* |
| funksiya | function | Ada malik, çağırıla bilən kod bloku *(Modul 05)* |

:::note[Termin seçimləri haqqında]
Azərbaycan dilində proqramlaşdırma terminologiyası hələ tam standartlaşmayıb. Bu kursda yuxarıdakı qarşılıqlar ardıcıl işlənir; rast gəldiyin başqa mənbələrdə fərqli variantlar ola bilər.
:::
