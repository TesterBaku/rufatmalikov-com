Ədədlər mətnlərdən fərqlidir: **dırnaqsız** yazılır. Dırnaqsız yazanda Python onları hesablayır:

<PyRunner
	id="ex-ferq"
	starterCode={`print(5 + 3)\nprint("5 + 3")`}
	height="4rem"
/>

Gördün? `5 + 3` hesablandı və `8` çıxdı, `"5 + 3"` isə adi mətn kimi çap olundu. **Dırnaq = mətn, dırnaqsız = ədəd.**

## Hesab əməlləri

| İşarə | Əməl | Nümunə | Nəticə |
|---|---|---|---|
| `+` | toplama | `7 + 2` | `9` |
| `-` | çıxma | `7 - 2` | `5` |
| `*` | vurma | `7 * 2` | `14` |
| `/` | bölmə | `7 / 2` | `3.5` |
| `//` | tam bölmə | `7 // 2` | `3` |
| `%` | qalıq | `7 % 2` | `1` |
| `**` | qüvvət | `7 ** 2` | `49` |

`//` və `%` cütlüyünü belə yadda saxla: 7 konfeti 2 uşağa bölsək — hərəsinə `7 // 2 = 3` konfet düşür, `7 % 2 = 1` konfet artıq qalır. 🍬

## Python — superkalkulyator

Bir gündə neçə saniyə var? Hesablamağa nə var ki:

<PyRunner
	id="ex-saniye"
	starterCode={`print(24 * 60 * 60)\nprint(2 ** 100)`}
	height="4rem"
/>

İkinci sətrə bax: 2-nin 100-cü qüvvəti — adi kalkulyator bunu bacarmır, Python isə gözünü də qırpmır. 😎
