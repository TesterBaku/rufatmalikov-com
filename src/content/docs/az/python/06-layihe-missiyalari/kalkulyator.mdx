Bu modul fərqlidir: dərs yoxdur, **layihə** var. Hər səhifə — öyrəndiklərini birləşdirən bir əsl proqram. Hazır kodu kimsə verməyəcək — plan var, qalanı səndədir. 😎

:::tip[Bu layihədə işlədəcəksən]
`input()` + `int()` (Modul 01) · `if/elif/else` (Modul 02) · f-string (Modul 01)
:::

## Plan

1. İstifadəçidən **birinci ədədi** al (`int(input(...))`)
2. **İkinci ədədi** al
3. **Əməli** al: `+`, `-`, `*` və ya `/` (bu, mətndir — `int()` lazım deyil!)
4. `if/elif` ilə əməli yoxla və uyğun nəticəni hesabla
5. Nəticəni `f-string` ilə gözəl formada çap et: `8 * 2 = 16`

Bonus ideya (istəyə görə): tanımadığı əməl üçün `else` qolunda «Belə əməl bilmirəm» desin.
