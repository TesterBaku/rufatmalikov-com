Dırnaq içindəki hər şeyə proqramlaşdırmada **mətn** deyilir (ingiliscə: *string*). Python mətnlərlə çox maraqlı şeylər edə bilir.

:::tip[Bu modulda nə öyrənəcəksən]
Bu modulun 4 dərsində Python ilə «danışmağı» öyrənəcəksən: mətnlər, rəqəmlər, dəyişənlər və proqramın səndən məlumat istəməsi (`input`).
:::

## Mətnləri birləşdir: +

`+` işarəsi iki mətni yapışdırır:

<PyRunner
	id="ex-birlesdir"
	starterCode={`print("Salam, " + "Aysel!")\nprint("Py" + "thon")`}
	height="5rem"
/>

Diqqət: `"Salam,"` sözündən sonra boşluq qoymasan, sözlər bitişik çıxar. Yoxla! 🙂

## Mətni təkrarla: *

`*` işarəsi mətni istədiyin qədər təkrarlayır:

<PyRunner
	id="ex-tekrar"
	starterCode={`print("Na" * 4 + " Batman!")\nprint("=" * 30)\nprint("🎉" * 5)`}
/>

`"=" * 30` — otuz dənə bərabər işarəsi. Cədvəl və çərçivə düzəltmək üçün əla fənddir.

## Tək, yoxsa cüt dırnaq?

İkisi də olar — Python üçün fərqi yoxdur:

```python
print("Salam")
print('Salam')
```

Amma mətnin **içində** dırnaq varsa, çöldəkini fərqli seç:

<PyRunner
	id="ex-dirnaq"
	starterCode={`print('Müəllim dedi: "Afərin!"')`}
	height="4rem"
/>
