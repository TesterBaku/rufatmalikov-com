İndiyə qədər proqramların yalnız danışırdı. İndi onlara **dinləməyi** öyrədək: `input()` istifadəçidən məlumat alır.

:::note[Bizim meydançada input() necə işləyir?]
Adi kompüterdə `input()` proqramı dayandırıb istifadəçinin yazmasını gözləyir. Bizim kod meydançasında isə cavabları **əvvəlcədən** «Daxiletmələr» qutusuna yazırsan — hər sətirdə bir cavab. Proqram `input()` çağırdıqca cavabları sıra ilə oradan götürür.
:::

## İlk söhbət

Aşağıdakı nümunədə «Daxiletmələr» qutusuna artıq `Aysel` yazılıb. Qutunu açıb bax, sonra işə sal:

<PyRunner
	id="ex-input"
	starterCode={`ad = input("Adın nədir? ")\nprint(f"Salam, {ad}! Tanış olduğuma şadam.")`}
	inputs={'Aysel'}
	height="5rem"
/>

`input("Adın nədir? ")` — sualı göstərir, cavabı götürür və `ad` qutusuna qoyur. Daxiletmələr qutusundakı adı dəyişib yenidən işə sal!

## Diqqət: input() həmişə mətn qaytarır

Tələ burdadır. İstifadəçi `12` yazsa belə, `input()` onu **mətn** kimi qaytarır — `"12"`. Mətnlə hesab aparmaq olmaz:

<PyRunner
	id="ex-tele"
	starterCode={`yas = input("Neçə yaşın var? ")\nprint(yas + 1)`}
	inputs={'12'}
	height="5rem"
/>

İşə sal — xəta görəcəksən: Python deyir ki, mətnlə rəqəmi toplaya bilmirəm. Həll: `int()` ilə mətni **tam ədədə** çevir:

<PyRunner
	id="ex-int"
	starterCode={`yas = int(input("Neçə yaşın var? "))\nprint(f"Gələn il {yas + 1} yaşın olacaq!")`}
	inputs={'12'}
	height="5rem"
/>

Qayda sadədir: **rəqəmlə hesab lazımdırsa — `int(input(...))`.**
