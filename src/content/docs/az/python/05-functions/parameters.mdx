`salamla()` həmişə eyni şeyi deyir. Bəs `print` necə hər dəfə **fərqli** şey çap edir? Çünki ona mötərizədə məlumat veririk. Öz funksiyamıza da verə bilərik — buna **parametr** deyilir.

## Parametrli funksiya

<PyRunner
	id="ex-param"
	starterCode={`def salamla(ad):\n    print(f"Salam, {ad}!")\n\nsalamla("Aysel")\nsalamla("Tural")\nsalamla("Nigar")`}
	height="8rem"
/>

`def salamla(ad):` — `ad` parametrdir: funksiyanın içində adi dəyişən kimi işləyir, dəyərini isə **çağırış** verir. `salamla("Aysel")` → `ad = "Aysel"` olur.

## Bir neçə parametr

Vergüllə ayır — sıra vacibdir:
